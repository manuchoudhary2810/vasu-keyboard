# Pink Fluffy Bunny Keyboard (Android Studio project)

A starter Android system keyboard inspired by the pink plush/floral keyboard screenshot.

## Build and install
1. Open this project folder in Android Studio.
2. Let Gradle sync and install any requested Android SDK components.
3. Choose **Build > Build APK(s)**.
4. Install the generated APK on your Android phone.
5. Open **Pink Fluffy Bunny Keyboard**.
6. Tap **Enable keyboard** and enable it in Android settings.
7. Tap **Choose keyboard** and select it.

## Features
- Android InputMethodService keyboard
- Pink gradient, rounded, plush-inspired keycaps
- Bunny and flower accents, suggestion strip, letter and symbol rows
- Backspace, enter, emoji and symbol toggle

## Limitations
This is a functional starter project, not a pixel-perfect clone. Gradients simulate plush texture; photographic fur textures and predictive typing are not included. It has no network permissions or analytics. Test before using as a daily keyboard.
